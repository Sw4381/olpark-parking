누리집 예상 이용률과 실측

올림픽공원 누리집 "주차장 예상 이용률 서비스"가 게시한 값과, 같은 시각 실시간 주차현황 API의 실측을 나란히 둡니다.

유입 속도와 만차 도달 시각은 최근 30분 변화를 그대로 이은 단순 계산입니다. 예측 모델 기준의 이상 유입 경보는 모델 검증이 끝나면 이 화면에 추가됩니다.

실측은 10분 주기 수집 기록이며, GitHub Actions 사정으로 간격이 벌어질 수 있습니다.
