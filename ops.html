누리집 예상 이용률과 실측

올림픽공원 누리집 "주차장 예상 이용률 서비스"가 게시한 값과, 같은 시각 실시간 주차현황 API의 표시값을 나란히 둡니다. 이 표만 보정하지 않은 표시값 기준입니다.

주차 대수는 동2·남2·북2문 기준입니다. 실시간 주차현황 API 값은 2025년 입출차 기록으로 복원한 값보다 일정하게 크게 나와, 그 차이를 추정해 뺀 값을 씁니다.

예상은 2025년 입출차정보에서 만든 요일·공연 조건별 패턴에, 지금 실측과 패턴의 차이를 반영한 값입니다. 실측은 10분 주기 수집 기록이며 GitHub Actions 사정으로 간격이 벌어질 수 있습니다.
